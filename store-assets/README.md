# Google Play assets

- `chattermore-store-icon.png`: 512 × 512 Play Store icon derived from the
  app's launcher vector.
- `chattermore-feature-graphic.png`: 1024 × 500 opaque Play Store feature
  graphic.
- `feature-graphic-background-generated.png`: generated background source used
  for the feature graphic.
- `screenshots/01-conversation-overview.png`: conversation directory with
  fictional channels, direct messages, unread state, and recent activity.
- `screenshots/02-active-channel.png`: fictional channel messages, mentions,
  and presence.
- `screenshots/03-direct-message.png`: fictional one-to-one conversation with
  an edited message.
- `screenshots/04-attachments-and-previews.png`: fictional file cards, video,
  reserved `example.com` link preview, and composer.
- `screenshots/05-notification-settings.png`: notification preferences and the
  privacy-policy action.

The phone screenshots are 1080 × 1920 opaque RGB PNGs captured from the
deterministic benchmark build on a Pixel 7a. The benchmark app was installed
with cleared app data and did not connect to a server. All teams, channels,
people, messages, timestamps, URLs, and attachments are fictional fixture data.
System bars were removed locally before the final images were written.
