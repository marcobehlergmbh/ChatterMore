# Google Play assets

- `chattermore-store-icon.png`: 512 × 512 Play Store icon derived from the
  app's launcher vector.
- `chattermore-feature-graphic.png`: 1024 × 500 opaque Play Store feature
  graphic.
- `feature-graphic-background-generated.png`: generated background source used
  for the feature graphic.

Phone screenshots must be captured from the deterministic benchmark build or a
sanitized demo server at 1080 × 1920 or higher. Do not use real accounts,
credentials, server hostnames, or customer information.
